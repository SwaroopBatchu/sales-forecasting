## 🎯 Project Overview

This project builds a complete AI-powered sales forecasting system for a multi-category retail business:

- Generates 3 years of realistic daily sales data across 5 product categories
- Trains **Facebook Prophet** for interpretable seasonality forecasting
- Trains **LSTM (TensorFlow/Keras)** for non-linear pattern recognition
- Both models outperform a naive seasonal baseline (+19pp accuracy)
- **OpenAI GPT API** auto-generates plain-language reports for 3 audience types
- **Streamlit app** enables 60+ non-technical users to explore forecasts without analyst support

## 🚀 Quick Start

### 1. Clone and install
```bash
git clone https://github.com/SwaroopBatchu/sales-forecasting.git
cd sales-forecasting
pip install -r requirements.txt
```

### 2. Generate sales data
```bash
python src/generate_data.py
```

### 3. Train forecasting models
```bash
cd src
python train.py
```
*(Training takes 5–10 minutes for all 5 categories)*

### 4. Launch the Streamlit app
```bash
streamlit run src/app.py
```

### 5. Enable AI reports (optional)
```bash
export OPENAI_API_KEY="your-key-here"
```
Without a key, the app uses a built-in mock report generator.

## 🤖 AI Report Types

| Audience | Focus |

| **Analyst** | Detailed trend drivers, risk factors, and statistical context |

## 📈 Dashboard Features

- **4 KPI cards** — total revenue, avg daily sales, best month, total units
- **Interactive forecast chart** — actual vs forecast with 95% confidence interval
- **Horizon slider** — adjust forecast from 30 to 365 days
- **Monthly trend chart** — 3-year revenue by month
- **Category comparison** — side-by-side revenue and daily averages
- **AI report generator** — one-click GPT summary for chosen audience
- **CSV export** — download historical or forecast data
